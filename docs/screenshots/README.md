## How to recapture

1. Install the extension from the [Chrome Web Store](https://chromewebstore.google.com/detail/Pendo%20Install%20Validator/ihcmfkfdfpoiadcpleapkjeppmephpfa), or load unpacked from `extension/` during development.
2. Navigate to a page with Pendo installed and click the extension icon.
3. Run validation, then take a screenshot of the panel / page.
4. Crop and save over the corresponding file in this folder.
